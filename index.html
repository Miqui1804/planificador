☁️ Configurar sincronización con Google

Sigue estos pasos una sola vez. Tarda unos 3 minutos y es completamente gratuito.

  1. Ve a script.google.com e inicia sesión con tu Google
  2. Haz clic en "Nuevo proyecto"
  3. Borra el código que hay y pega este:
const SHEET_NAME = 'datos'; function doGet(e) { const sheet = SpreadsheetApp.openById(e.parameter.id).getSheetByName(SHEET_NAME); const data = sheet.getRange(1,1).getValue(); return ContentService.createTextOutput(data || '{}').setMimeType(ContentService.MimeType.JSON); } function doPost(e) { const payload = JSON.parse(e.postData.contents); const sheet = SpreadsheetApp.openById(payload.id).getSheetByName(SHEET_NAME) || SpreadsheetApp.openById(payload.id).insertSheet(SHEET_NAME); sheet.getRange(1,1).setValue(payload.data); return ContentService.createTextOutput('ok'); }

  2. Tipo: Aplicación web · Ejecutar como: Yo · Acceso: Cualquier usuario
  3. Haz clic en Implementar → copia la URL de la aplicación web
